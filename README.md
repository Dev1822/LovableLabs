# Lovable Labs Website

A simple **Lovable Labs website** built using **HTML and CSS**.  
This project recreates a modern company-style website with multiple pages such as Home, About, Benefits, and Contact.

🌐 **Live Demo:**  
https://devpatel-lovelablelabs.netlify.app/

---

## Features

- Clean tech company themed UI
- Multiple pages (Home, About, Benefits, Contact)
- Custom CSS styling
- Responsive layout
- Simple and organized structure

---

## Tech Stack

**Frontend**
- HTML5
- CSS3

**Tools**
- Git
- GitHub
- Netlify (Deployment)
